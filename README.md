# 📊 HR Analytics Dashboard – Excel

## 📌 Project Overview

This project is an interactive **HR Analytics Dashboard** created using Microsoft Excel.

The dashboard transforms raw employee data into meaningful insights about workforce distribution, employee demographics, departments, job roles, and key HR metrics.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard Design

## 📈 Key Insights

The dashboard provides insights into:

- 👥 Employee headcount and workforce distribution
- 📊 Employee demographics
- 🏢 Department-wise analysis
- 💼 Job role analysis
- 📈 Employee trends
- 📌 Key HR performance metrics

## 🎯 Project Objective

The main objective of this project is to analyze HR data using Excel and create an interactive dashboard that helps understand workforce patterns and supports data-driven decision-making.
